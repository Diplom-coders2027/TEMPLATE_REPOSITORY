## 🚀 Быстрый старт (локальный запуск)

Проект спроектирован для запуска в 2–3 команды с использованием Docker Compose:

```bash
# 1. Склонировать репозиторий
git clone https://github.com/Diplom-coders2027/<ВАШ_РЕПОЗИТОРИЙ>.git
cd <ВАШ_РЕПОЗИТОРИЙ>

# 2. Скопировать конфигурацию переменных окружения
cp .env.example .env

# 3. Запустить проект и сервисы
docker compose up --build
```

> **Примечание:** После запуска приложение будет доступно по адресу `http://localhost:8080`, документация API — по адресу `http://localhost:8080/docs`.

## 📅 Чек-лист этапов сдачи ВКР

Сдача этапов происходит **строго через Pull Request** с рецензированием научным руководителем (см. [CONTRIBUTING.md](CONTRIBUTING.md)).

- [ ] **Этап 0. Подготовительный (до ДД.ММ.ГГГГ)**
  - [ ] Согласование и утверждение темы ВКР
  - [ ] Оформление технического задания (ТЗ) и календарного плана
  - [ ] Формирование и первичная настройка репозитория проекта
- [ ] **Этап 1. Аналитический обзор и проектирование (до ДД.ММ.ГГГГ)**
  - [ ] Анализ предметной области и существующих аналогов
  - [ ] Формирование функциональных и нефункциональных требований
  - [ ] Проектирование архитектуры системы (UML/C4-диаграммы, схема БД)
  - [ ] Черновик разделов 1 и 2 пояснительной записки в папке `docs/`
- [ ] **Этап 2. Разработка MVP / прототипа (до ДД.ММ.ГГГГ)**
  - [ ] Реализация базового ядра системы и модели данных
  - [ ] Реализация основного API / пользовательского интерфейса
  - [ ] Настройка локального развертывания через Docker Compose
  - [ ] Черновик раздела 3 пояснительной записки
- [ ] **Этап 3. Полнофункциональная реализация и тестирование (до ДД.ММ.ГГГГ)**
  - [ ] Завершение всей запланированной функциональности
  - [ ] Покрытие кода модульными и интеграционными тестами
  - [ ] Проведение нагрузочного / пользовательского тестирования
  - [ ] Подготовка раздела тестирования и анализа результатов
- [ ] **Этап 4. Оформление документации и подготовка к защите (до ДД.ММ.ГГГГ)**
  - [ ] Пояснительная записка оформлена строго по стандарту (ГОСТ)
  - [ ] Проверка на заимствования (Антиплагиат) — оригинальность >= X%
  - [ ] Подготовка презентации и доклада
  - [ ] Прохождение предзащиты
- [ ] **Этап 5. Финальная сдача и защита (до ДД.ММ.ГГГГ)**
  - [ ] Получение отзыва научного руководителя
  - [ ] Получение рецензии (при необходимости)
  - [ ] Защита ВКР перед Государственной экзаменационной комиссией (ГЭК)
